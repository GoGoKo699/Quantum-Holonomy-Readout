# Learning route

Start with the [eight-photon example](WALKTHROUGH.md) to see how local detection records reveal the relationship between two polarization loops. The [30-milestone map](MILESTONES.md) then connects the source model, the impossibility result, the receiver and its statistical cost.

The educational anchor is Stephen D. Bartlett, Terry Rudolph and Robert W. Spekkens, *Reference frames, superselection rules, and quantum information* (2007). The [source bridge](BARTLETT_RUDOLPH_SPEKKENS_BRIDGE.md) identifies the relevant pages, translates the notation and explains how the project uses collective frame averaging at many stations.
